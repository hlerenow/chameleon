# 快捷键

以下快捷键由 `HotkeysPlugin` 默认注册。快捷键作用于设计器画布；输入框等可编辑控件可能由控件自身处理按键。

| 快捷键                | 作用                                           |
| --------------------- | ---------------------------------------------- |
| `Ctrl/⌘ + C`          | 复制当前节点                                   |
| `Ctrl/⌘ + Z`          | 撤销                                           |
| `Ctrl/⌘ + Shift + Z`  | 重做                                           |
| `Backspace`           | 删除当前节点                                   |
| `↑` / `W`             | 向上选择；无可选兄弟节点时尝试选择父节点       |
| `↓` / `S`             | 向下选择；无可选兄弟节点时尝试选择第一个子节点 |
| `Alt + ↑` / `Alt + W` | 选择上一个兄弟节点                             |
| `Alt + ↓` / `Alt + S` | 选择下一个兄弟节点                             |
| `⌘ + ↑` / `⌘ + ↓`     | 选择上/下一个兄弟节点                          |

源码中的 `⌘` 使用 key code 93 注册，具体表现受操作系统和浏览器键盘事件影响。`Ctrl`、`Alt`、方向键等名称由 Hotkeys 的 keymap 解析。

## 禁用或增加快捷键

只有加载 `HotkeysPlugin` 才会注册默认快捷键。插件实例暴露 `addHotAction(actionKey, callback)` 和 `setDisable(status)`，可在插件上下文中扩展或临时禁用；自定义时应避免覆盖输入控件和浏览器保留组合键。
