快捷键由 `HotkeysPlugin` 提供。默认插件列表已包含它；自定义 `plugins` 时省略它，快捷键不会生效。

## 常用操作

| 快捷键                | 作用                                           |
| --------------------- | ---------------------------------------------- |
| `Ctrl/⌘ + C`          | 复制当前节点                                   |
| `Ctrl/⌘ + Z`          | 撤销                                           |
| `Ctrl/⌘ + Shift + Z`  | 重做                                           |
| `Ctrl/⌘ + +`          | 放大画布                                       |
| `Ctrl/⌘ + -`          | 缩小画布                                       |
| `Ctrl/⌘ + 0`          | 重置画布缩放比例为 100%                        |
| `Backspace`           | 删除当前节点                                   |
| `↑` / `W`             | 向上选择；无可选兄弟节点时尝试选择父节点       |
| `↓` / `S`             | 向下选择；无可选兄弟节点时尝试选择第一个子节点 |
| `Alt + ↑` / `Alt + W` | 选择上一个兄弟节点                             |
| `Alt + ↓` / `Alt + S` | 选择下一个兄弟节点                             |
| `⌘ + ↑`               | 选择上一个兄弟节点                             |
| `⌘ + ↓`               | 选择下一个兄弟节点                             |

实际行为取决于是否同时安装历史记录插件，以及当前焦点位置。输入框聚焦时，浏览器或输入控件的快捷键可能优先。

## 启用方式

```tsx
import { Engine, plugins } from '@chamn/engine';

<Engine plugins={[plugins.DesignerPlugin, plugins.HistoryPlugin, plugins.HotkeysPlugin]} schema={schema} />;
```

## 自定义策略

1. 保留 `HotkeysPlugin`，仅在业务层拦截冲突组合键。
2. 不加载 `HotkeysPlugin`，由业务自行处理按键并调用 Engine/插件 API。

避免全局捕获 `Ctrl/Cmd + Z` 后直接改 Schema；撤销栈应由历史记录插件维护。替换行为时，先确认焦点不在输入框。
