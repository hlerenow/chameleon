# 编辑器基础操作

## 快速设置元素宽高

1. 在画布或大纲树中选中元素。
2. 打开右侧属性面板的样式区域。
3. 在尺寸/布局输入框中设置 `width`、`height`；需要响应式效果时切换对应断点再设置。
4. 需要精确控制时打开 CSS 编辑器，直接修改 CSS 属性。

尺寸值应使用组件支持的 CSS 值，例如 `240px`、`100%` 或 `auto`。修改后以画布渲染结果为准；如果组件自身样式或父容器布局覆盖了尺寸，检查 CSS 优先级和父节点布局。

## 设置颜色、边框和阴影

右侧样式面板提供背景、边框、阴影、字体等编辑入口。颜色可以通过颜色选择器设置；复杂或未暴露的属性可在 CSS 编辑器中补充。不要直接修改导出的页面对象来绕过面板，这会使历史记录和画布同步失效。

## 使用大纲树

大纲树用于查看页面节点层级、选中节点和调整层级关系。画布选中与大纲树选中共享当前节点状态；定位到深层节点时优先使用大纲树。

## 保存页面

通过 `onReady` 获取 `ctx.engine.pageModel`，使用 `pageModel.export()` 导出当前页面协议，再持久化到业务后端。加载时将协议作为 `schema` 传回 `Engine`，或调用 `engine.updatePage(schema)` 更新页面。

## 常见限制

- 页面根节点不能像普通组件一样删除。
- 某些物料会通过 `advanceCustom` 定制右侧面板和快速添加行为。
- 修改外部数据后，如果画布没有同步，优先使用 `engine.updatePage()` 或 `engine.refresh()`，不要只修改 React state 中的对象引用。
